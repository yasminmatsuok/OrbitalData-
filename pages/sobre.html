// SOBRE O PROJETO

O que é o
AstroData?

Uma plataforma inteligente que usa dados abertos de satélites da NASA e ESA para monitorar emissões de carbono e mudanças climáticas em tempo real — tornando informações complexas acessíveis para empresas, governos e pesquisadores.

🛰️ NASA / ESA 🌿 Carbono 🗺️ Brasil ⚠️ Alertas
01

// MISSÃO

Democratizar o acesso a dados satelitais climáticos, transformando informações científicas complexas em insights acionáveis para qualquer pessoa.

02

// VISÃO

Ser a principal plataforma de monitoramento climático da América Latina, contribuindo para decisões mais sustentáveis em escala global.

// PROBLEMA & SOLUÇÃO

Por que o AstroData existe?

// O PROBLEMA

O Brasil e o mundo enfrentam uma crise climática crescente, mas as ferramentas de monitoramento disponíveis são:

✗ Complexas demais para não-cientistas
✗ Dados fragmentados em dezenas de portais
✗ Relatórios com meses de atraso
✗ Custo proibitivo para pequenas empresas

// A SOLUÇÃO

O OrbitalData centraliza e simplifica esses dados em uma única plataforma intuitiva:

✓ Interface simples e acessível
✓ Dados de múltiplos satélites integrados
✓ Monitoramento em tempo real 24/7
✓ Gratuito para pesquisadores e governo

// FONTES DE DADOS

De onde vêm os dados?

🚀
NASA Earthdata
Satélites Aqua e Terra — temperatura, cobertura vegetal e CO₂ atmosférico
🌍
ESA Copernicus
Sentinel-3 e Sentinel-5P — qualidade do ar, emissões e temperatura oceânica
🌿
INPE Brasil
Monitoramento do desmatamento na Amazônia e focos de queimadas
🌡️
NOAA Climate
Dados históricos de temperatura, precipitação e eventos extremos
💨
Global Carbon Project
Emissões globais de CO₂ e metas do Acordo de Paris
🏔️
NSIDC
Monitoramento de geleiras árticas e nível do mar
// DESENVOLVIMENTO

Como foi construído

Etapa 01
Pesquisa e Planejamento
Identificação do problema, pesquisa de dados abertos da NASA/ESA e definição da arquitetura da plataforma.
Etapa 02
Design e Identidade Visual
Criação do sistema de design com paleta espacial, tipografia técnica e componentes reutilizáveis.
Etapa 03
Desenvolvimento Front-End
Implementação das páginas em HTML5, CSS3 e JavaScript puro, com gráficos SVG e mapa interativo.
Etapa 04
Integração de Dados
Conexão com dados mockados baseados em fontes reais da NASA, ESA e INPE para demonstração.
Etapa 05
Entrega — Global Solution FIAP
Finalização, versionamento no GitHub e entrega do projeto para avaliação.
