# 🛰️ OrbitalData

> Plataforma de Análise Climática e Monitoramento de Carbono via Dados Satelitais

![OrbitalData](assets/orbitaldata.png)

## 📋 Descrição

O **OrbitalData** é uma plataforma web inteligente que utiliza dados abertos de satélites da **NASA** e **ESA** para monitorar emissões de carbono, desmatamento e mudanças climáticas em tempo real. O projeto transforma informações científicas complexas em visualizações acessíveis para empresas, governos e pesquisadores.

**Problema que resolve:** O Brasil e o mundo precisam monitorar emissões de carbono e impactos climáticos em tempo real, mas as ferramentas existentes são complexas e inacessíveis para a maioria das pessoas e organizações.

---

## 🚀 Funcionalidades

- 📊 **Dashboard** em tempo real com métricas de CO₂, temperatura e queimadas
- 🗺️ **Mapa interativo** do Brasil com dados climáticos por região
- ⚠️ **Sistema de alertas** para anomalias e eventos climáticos
- 🛰️ **Monitoramento de satélites** NASA/ESA em operação
- 📄 **Relatórios automáticos** exportáveis em CSV/PDF
- 🔴 **Ticker ao vivo** com dados atualizados a cada 90 minutos

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura semântica das páginas |
| CSS3 | Estilização, animações e responsividade |
| JavaScript | Interatividade, gráficos SVG e dados dinâmicos |
| SVG | Gráficos de linha, barra, gauge e mapas |
| Google Fonts | Tipografia Share Tech Mono + Exo 2 |
| Git / GitHub | Versionamento e colaboração |

**Fontes de dados (mockados com base em dados reais):**
- NASA Earthdata — satélites Aqua e Terra
- ESA Copernicus — Sentinel-3 e Sentinel-5P
- INPE Brasil — desmatamento e queimadas
- NOAA Climate — dados históricos
- Global Carbon Project — emissões globais
